Problem 1 – Linear Search

Challenges Faced:
The main challenge was understanding recursion and how the function moves to the next index.
I also had to handle duplicate values.

Solution Applied:
I passed the current index to the recursive function and called it for the next index until
the target was found or the array ended. If duplicates exist, it returns the first occurrence.
